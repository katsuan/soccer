# ⚽ スタメン・作戦盤

サッカー・フットサルのスタメン発表と作戦盤。選手をピッチに並べて、[おくるん](https://katsuan.github.io/line-share/)の「お知らせカード」で LINE にカードとして送れます。試合結果のカードも作れます。GitHub Pages でそのまま動く静的サイトです。

公開URL: https://katsuan.github.io/soccer/

## できること

- **スタメン・作戦盤**
  - 作戦盤は1枚のカードにまとめる：右上で人数とフォーメーション、その下にピッチ、ピッチのすぐ下に操作（相手・ボール・ペン・選手・戻す）。「位置をフォーメーションに戻す」で並べ直す
  - フォーメーションはサッカー 11人・サッカー 8人制・フットサル 5人から選ぶ。「− 11人 ＋」で1人ずつ増やす・減らす（GK を入れて 2〜11 人。退場で10人、7人制など）。ほかの選手の位置はそのままで、フォーメーションの欄は「10人」のようになる。相手は人数の違うフォーメーションも選べる
  - 自チーム・相手の色と、相手のフォーメーションは「🎨 チームの色・相手の並び」にたたむ（おくるんの基本の並び：紫・スカイ・リーフ・サンセット・ベリー＋カスタム。明るい色は背番号を濃く。GK はオレンジ、自チームがオレンジ系なら黒）。カードの選手の丸と見出しの帯も自チームの色になる
  - 選手の編集はモード制：「選手」を押している間だけ、タップで背番号・名前（選手名簿から選べる）。それ以外のときは、ドラッグで移動・タップで選ぶ（作戦盤の操作に集中）
  - 相手の人数：相手を出している間はピッチの上に「相手の人数 − 10人 ＋」と「11 対 10（数的有利）」が出て、自チームと違う人数にできる（退場・数的有利／不利の練習。ほかの相手の位置はそのまま。画像の見出しにも「11人 対 10人」と入る）
  - 作戦盤：相手（反対向きに並ぶ。消して出し直しても人数・位置は残る）・ボール（サッカーボールの絵）・ペンの線（矢印なしの線。色を選べる・線を全部消す）。「戻す」は移動・線・表示の切り替え・人数やフォーメーションの変更を1つずつ戻す
  - 📁 保存した作戦：「ビルドアップ」「コーナーキック」など場面ごとに、選手の位置・相手・ボール・線を名前を付けて保存（同じ名前は上書きの確認。30件まで。チームの色は含めない）。開く（今の作戦盤に呼び出す。「戻す」で元に戻せる）・複製・名前を変える・消す。この端末（localStorage の `soccer:tactics`）に残る
  - 範囲選択：ピッチの何もない所をなぞると、中の選手・相手・ボールが選ばれ、1つをドラッグすると全部が一緒に動く。Ctrl・⌘・Shift を押しながらタップ／なぞると選択に足す
  - フットサルはゴール前が半円（D形）のエリア、サッカーは四角いペナルティエリア
  - 「💬 LINE で共有」の1つのボタンから、送り方をシートで選ぶ
    - 「💬 カードで送る」：おくるんに渡し、ピッチに選手を並べたカードで送る（相手・ボール・線はカードには入らない）。カードのピッチをタップすると、同じ配置の作戦盤が開く
    - 「🖼️ 画像で送る」：作戦盤の画像（相手・ボール・線も入る）を、おくるんの画像サーバー（無料。しばらく使わないと眠り、時間がたつと画像が消えることがある）に保存し、その画像を写真にしたお知らせカードをおくるんで開く（`imageUrl`）。ページを開いた時点で画像サーバーを起こしておく
    - 「📷 画像で保存する」：相手・ボール・線も入った画像（長押し・共有メニュー・ダウンロード）
  - 試合の情報・選手名簿はたたんだ欄
- **試合結果**：最終スコア。前後半・延長・PK と、得点・MVP はたたんだ欄（どれも任意）。前半／後半／延長／PK（入れたものだけ出る。同点で PK があれば PK で勝ち負け）・得点（自チーム／相手、時間と名前）・MVP・ひとこと →「💬 LINE で共有」
- 入力した内容と選手名簿はこの端末（localStorage）に残る

## おくるんへの渡し方

`https://liff.line.me/<おくるんの LIFF ID>/card/?kind=lineup|match&data=<JSON を UTF-8 → base64url>&headerTitle=…&title=…&from=soccer`

| kind | data |
|---|---|
| `lineup` | `{ m: "futsal"\|"soccer", f: フォーメーション, t: チーム, o: 相手, s: 控え, c: 自チームの色, pl: [[背番号, 名前, x, y], ...] }`（x・y は 0〜100。左上から、上が攻める向き。先頭が GK） |
| `match` | `{ t, o, us, th（最終。延長を含む）, hu・ht（前半）, su・st（後半）, eu・et（延長）, pu・pt（PK）, g: [["u"\|"t", 分, 名前], ...], mvp }`（内訳と PK はなければ空） |

おくるんは中身を確かめて（人数・長さ・位置の範囲）、ピッチの図やスコアをカードの部品で描いて送ります（画像のアップロードは要らない）。おくるんの「⚽ 配置・結果を直す」からは `?tab=lineup|result&data=…` でこのページに戻ってきます。
