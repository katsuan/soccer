# ⚽ さくせん盤（SAQSEN）

サッカー・フットサルのスタメン発表・作戦盤・試合結果のツール。名前は「さくせん盤」（英字は SAQSEN。おくるん＝OQRN と同じ作り方）。ふだん見せるのはひらがなの「さくせん盤」、英字は見出しの下の小さな文字やロゴに使う。送るカードはおくるんで作る。

アイコン（`icon.svg`・`apple-touch-icon.png`・`icon-512.png`）は `python3 tools/icon.py` で作る：おくるんと同じ角の丸い四角に、ピッチの緑。白い S 字の作戦の線（なだらかなインテグラル ∫ のような S。パスの通り道で、さくせんの S）と両端の選手2人、うっすらピッチの線。センターサークルの右下にサッカーボールを置き、サークル＋ボールで Q にも見せる（SAQSEN の Q）。

ファビコンは `icon.svg`（使えないブラウザ向けに `icon-32.png`）、ホーム画面に追加したとき用に `manifest.webmanifest`（四隅まで塗った `icon-maskable-512.png`）。共有したときの画像（`ogp.png`、1200×630）は `python3 tools/ogp.py` で作る。

横長のロゴ（`logo.svg`）も同じスクリプトで作る：ピッチ（盤）の上に「SAQSEN」を白い字で並べ、最初の S・A・E・N はフォント（Jua）、Q はセンターサークル（ハーフウェーラインの真ん中）＋右下のボール。Q の後ろの S はアイコンと同じ線の S で、左下の端（選手の丸）がちょうどボールの下に隠れるところまで寄せる（形は変えない）。見出しの下に出す。

サッカー・フットサルのスタメン発表と作戦盤。選手をピッチに並べて、[おくるん](https://katsuan.github.io/line-share/)の「お知らせカード」で LINE にカードとして送れます。試合結果のカードも作れます。GitHub Pages でそのまま動く静的サイトです。

公開URL: https://katsuan.github.io/soccer/


画面の部品（見出しの行・カード・チップ・ボタン・ラベル）は、おくるんの Q キット（`https://katsuan.github.io/line-share/shared/ui.css`。使い方はおくるんの README）の名前（`ls-brand`・`ls-panel`・`ls-chip`・`ls-chips`・`ls-button`・`ls-label`）。色と字は `style.css` の `:root`（`--ls-accent` など。紫はおくるんと同じ）。チームの色の丸・ピッチ・選手のこま・得点の欄など、さくせん盤にしかない見た目と、並ぶ数が多いぶんの大きさの調整は `style.css` に残す。
## できること

タブは分けず1ページ。はじめて開いた人にだけ、作戦盤の上に3行の案内（Q キットの firstTip。「わかった」で消え、この端末では次から出ない。前の案内を閉じた人には出さない）。上から 作戦盤 → 📁 保存した作戦 → 👕 チーム・試合結果 → 🏟️ 会場情報 → 👤 選手名簿 → 「カードで送る」「📷 画像で保存」。

- **作戦盤**（1枚のカード）
  - 右上でコート（サッカー 11人・サッカー 8人制・フットサル 5人）を選ぶ。ピッチの下に道具：👁️ 表示・📐 並び・✏️ ペン・↩️ 戻す（盤の下の欄は、表示・並び・ペンのどれか1つだけ開く）。選手のこと（背番号・名前・印）は、選手の長押しで
  - 横のコート：横に広い画面（スマホの横向き・パソコン。幅 600px 以上で横が長い）では、自動で横のコート（自陣が左、攻める向きが右）。広い画面ではページも広げて盤を大きくする。「👁️ 表示」の「コート：自動／縦／横」で決めても使える。位置・線のデータはいつも縦のコートの % で持ち、描くとき・さわるときだけ 90° 回す（core.js の toView・fromView）。画像・カードはいつも縦
  - 👁️ 表示：盤に何を見せるか。相手（出さない／フルコート＝互い違い／コート別＝半分ずつ）・ボール・選手名・得点など（それぞれ 出さない／出す）。選手名・得点などを出さないと、画像・カードのリンクからも外す（入れたものは消えない）
  - 📐 並び：自チーム・相手のタブで、人数（GK を入れて 2〜16 人）・フォーメーション（プルダウン。「カスタム…」で 3241・4-4-1 のように入れる）・列ごとの形（2人：しぼる／ふつう／ワイド、3人：フラット／▲ 三角／▼ 逆三角、4人：フラット／◆ ダイヤ／▢ ボックス、5人：フラット／サイド前／アンカー）。相手を出しているときは「11 対 10（数的有利）」
  - 選手の長押し：自チームの選手を動かさずに長押しすると、ポップアップが出る（選手のことはここだけで変える）
    - 上の「10 たなか ✏️」をタップすると、背番号・名前を入れられる（選手名簿のボタンからも選べる。ほかの選手が使っている名前は薄く）
    - 印のボタン（🟨 イエロー・🟥 レッド・⚽ ゴール・👟 アシスト・赤いボールの OG）をタップすると1つ足す（試合中の記録。今の数は右上の丸。盤の印は2つ以上なら「⚽2」「🟨2」のように数で）。下の小さな − で1つ減らす
    - 「🔄 交代」（選手の行）：時間と入る選手（選手名簿からも。盤にいる選手は薄く）を入れる。丸（ポジション）はそのままで中の人が入れかわり、丸の右上に 🔄、交代前の選手（何人でも合計）の得点・OG はその右下に小さく ⚽・赤いボール。入れ替えは自由（一度下がった選手がまた入ってもよい）。出た選手の記録は残り（得点は得点者に名前で、カード・アシストは出た選手の分として結果のカードに）、ポップアップに「🔄 60' たなか → すずき（たなか：⚽🟨）」と出る。最後の交代は「最後の交代を元に戻す」で戻せる。結果のカードには「🔄 60' たなか → すずき」の行（おくるんの `sb`）。「試合結果をリセット」で交代の記録も消える（いまの選手はそのまま）
    - ⚽ ゴール・OG は、試合結果の得点者そのもの：足すと得点者（ゴールは自チーム側に選手の名前、OG は相手側に「名前（OG）」）とスコアに入り、− で消える。盤の ⚽ の印は得点者から数える。背番号・名前を変えると、得点者の名前もそろう
    - 変えるとすぐ盤に出る。× か外を触ると閉じる。押したまま動かしはじめると、ポップアップを閉じて移動になる
  - カード・アシストの印をまとめて消すボタンは「👁️ 表示」の中（印があるときだけ。得点者は「試合結果をリセット」で）
  - 相手の長押し：「相手10番 ✏️」をタップで背番号・名前（紅白戦など。選手名簿も両チームで使える）、「🔄 交代」も自チームと同じ（結果のカードには「相手 けんた → 相手 こうじ」）。自チームと同じ印のボタン（イエロー・レッド・ゴール・アシスト・OG。下の小さな − で減らす）。ゴールは試合結果の得点者に「相手10番」（OG は自チーム側に「相手10番（OG）」）として入り、スコアも合わせる。カード・アシストは相手の選手の印で、相手を出しているときは結果のカードにも「相手10番」で入る。相手のこまにも印が出る（盤・画像）
  - 印は丸の右下、GK の 🧤 は左下（作戦盤・画像・おくるんのカード）。絵文字が続くところは1/3ずつ重ねる。右の端で盤からはみ出す選手は、収まるところまで内側へずらす
  - 相手を出していないときはコート全体に並べる。フルコートは相手と互い違い（上から 相手GK → 相手DF → 自チームFW → 相手MF → 自チームMF → 相手FW → 自チームDF → 自チームGK）、コート別は自チームが下半分・相手が上半分。並べ直したとき、自チームとほとんど重なる相手は横に少しずらす
  - 範囲選択：ピッチの何もない所をなぞると、中の選手・相手・ボールが選ばれ、まとめて動く。「戻す」は移動・線・表示・人数やフォーメーションの変更を1つずつ戻す
  - フットサルはゴール前が半円（D形）のエリア、サッカーは四角いペナルティエリア
- **📁 保存した作戦**：場面ごとに選手の位置・相手・ボール・線を名前を付けて保存（30件まで。チームの色は含めない）。開く・複製・名前を変える・消す。この端末（`soccer:tactics`）に残る
- **👕 チーム・試合結果**：左が自チーム、右が相手。チーム名と色（チーム名の枠の中の左に色の丸 `[● チーム名]`。丸を押したとき・チーム名を入れているあいだは、チームの欄の下に横いっぱいの1行で 8 色（緑・黄・白・赤・青・紺・オレンジ・黒）とカスタム。上の小さな三角がそのチームの丸を指し、開いているあいだと入力中は枠のふちが緑。丸から開いたときは決まった色を選ぶとたたみ、入力中は色を選んでも出したまま（入れおわるとたたむ）。色の名前は画面に出さない。もう片方のチームと同じ色は、選べるが薄くして斜めの線。ろくがのアプリ版と同じ形・同じ色）、その下にスコア（キロっくの回数入力と同じ − 数 ＋。数は打っても入れられる）・得点の内訳（前後半・延長・PK）・得点者（左に自チーム、右に相手、真ん中に時間）・ひとこと（結果。MVP などもここに書く）。見出しの右は「FC青 2 - 1 赤SC」
  - 得点者を足す・消すと、スコアも合わせる（スコアが得点者の数とそろっていたとき。名前のわからない得点をスコアにだけ入れているときは、得点者の数より少なくならないようにだけする）
  - ひとことの下のひな形（＋ MVP・＋ よかったところ・＋ 次の試合）をタップすると、次の行に足して続きを打てる
  - 得点者は選手・相手の長押しとつながっている（長押しで足した得点はここに並び、ここで消すと盤の印も消える。ここで名前を書き換えると、盤のその選手（自チーム・相手）の名前と、同じ選手のほかの得点もそろう）。アシスト・カードの印は、そのまま結果のカードに入る
  - 「試合結果をリセット」：スコア・内訳・得点者・ひとこと（結果）を消す（チーム名・色はそのまま。盤の ⚽ の印も消える。カード・アシストの印も消すかを続けて聞く）
- **🏟️ 会場情報**：日にち・時間・場所・ひとこと（作戦盤。控えや集合時間などを改行して書く。＋ 集合・＋ 控え・＋ 持ち物・＋ ユニフォーム のひな形をタップで足せる）。場所は「保存」しておくと次から ▼ で選べ、保存済みの場所は同じボタンが「消す」になる（`soccer:venues`）。カードには「10/18（日）9:00」の形で入る
- **カードで送る**（おくるんのマーク）：送るカード（📋 さくせん盤・🏆 試合結果。横に2枚並べて小さく見せる）を選び、おくるんで1つのメッセージ（2枚なら横に並ぶ）にして送る。試合結果を入れてあれば、最初から2枚とも選んでおく。それぞれのカードを、おくるんで送るときと同じ並び（色の帯に見出し・日時 → タイトル → ひとことの枠 → ミニのピッチ／勝敗・スコア・得点者・アシスト・カード）で、送る前にシートに小さく描く（share.js の lineupPreviewEl・resultPreviewEl。おくるんの card/js/flex.js・soccer.js の見た目に合わせる）。「カードで送る（◯枚）」はシートの下に付いてくる。カードは画像を使わないので確実に届き、消えない。さくせん盤のカードは 👁️ 表示どおり（相手を出していれば相手も、選手名を出さないなら名前なし）。ピッチをタップすると、同じ配置の作戦盤が開く
  - 「🖼️ 作戦を画像で送る」：作戦盤の画像（相手・ボール・線も入る）を、おくるんの画像サーバー（無料。しばらく使わないと眠り、時間がたつと画像が消えることがある）に保存し、その画像を写真にしたお知らせカードをおくるんで開く。画像をタップすると同じ作戦盤が開く（1000 文字に収まるよう、線の点を間引き、入らなければ 選手の名前 → 線 → ボール → 相手 の順に外す）
- **📷 画像で保存**：相手・ボール・線も入った画像（長押し・共有メニュー・ダウンロード）
- なくした欄の中身は、ひとことの行へ移す（前の控え → ひとこと（作戦盤）、前の MVP → ひとこと（結果））
- 入力した内容と選手名簿はこの端末（localStorage）に残る

## ファイルの分け方

本体は役割ごとに分けたファイルを、index.html に書いた順に普通の `<script>` で読む（同じ範囲の変数 `state` などを使う。おくるんのお知らせカード `card/js/` と同じやり方）。はじめに動かすのは最後の `app.js`。

| ファイル | 中身 |
|---|---|
| `js/page.js` | ページ全体で使う小さな道具（$・季節の絵文字・角の丸い四角・色・日時の文字）。頭にファイルの一覧 |
| `js/formation.js` | フォーメーション・コート・選手の並ぶ位置 |
| `js/marks.js` | 選手の印（カード・ゴールなど）と得点者・交代・結果のカードに入れる名前 |
| `js/store.js` | 覚えておくこと（state。この端末に残す・端末やリンクの中身の形の確かめ・保存した作戦の形・戻す） |
| `js/link.js` | 受けとったリンク（?data=）を読む・リンクの文字を作る |
| `js/board.js` | 画面：ピッチの描き直し・相手・選手のこま・ドラッグ・範囲選択 |
| `js/ink.js` | ペン（作戦盤の線） |
| `js/tactics.js` | 作戦の保存・場所の保存 |
| `js/sheets.js` | 選手の入力シート・結果の得点 |
| `js/card.js` | 送るカード（おくるんへのリンク）・送る前の見本・作戦盤の画像のカード・天気（そらくる）のリンク |
| `js/image.js` | 作戦盤の画像（保存・カードの写真） |
| `js/events.js` | 操作（ボタン・入力） |
| `app.js` | 入口：はじめに動かす |
| `js/core.js`・`js/share.js` | 前の名前のファイル。前の index.html を覚えているブラウザ（LINE の中など）のために、新しいファイルを読むだけ。**2026-11-25 ごろに消す** |

ファイルの名前は Q のツール共通の決まり（q-oqrn の docs/structure.md）にそろえている。

おくるんのカードの URL（LIFF ID）は line-share の `shared/oqrn.js` から読む。

## おくるんへの渡し方

`https://liff.line.me/<おくるんの LIFF ID>/card/?kind=lineup|match&data=<JSON を UTF-8 → base64url>&headerTitle=…&title=…&from=soccer`

2枚（さくせん盤＋試合結果）のときは、2枚目のカードのパラメータをまるごと `card=` に入れる（`…&card=kind%3Dmatch%26data%3D…`）。

| kind | data |
|---|---|
| `lineup` | `{ m: "futsal"\|"soccer", f: フォーメーション, t: チーム, o: 相手, c: 自チームの色, pl: [[背番号, 名前, x, y], ...], op: 相手（同じ形）, oc: 相手の色 }`（👁️ 表示どおり：相手を出しているときだけ op・oc、選手名を出さないときは名前を空に）（x・y は 0〜100。左上から、上が攻める向き。先頭が GK） |
| `match` | `{ t, o, us, th（最終。延長を含む）, hu・ht（前半）, su・st（後半）, eu・et（延長）, pu・pt（PK）, g: [["u"\|"t", 分, 名前], ...], as: [[名前, 数], ...]（アシスト）, cd: [["y"\|"r", 名前, 数], ...]（カード）, sb: [[分, 出た選手, 入った選手], ...]（交代） }`（内訳と PK はなければ空。as・cd・sb は作戦盤の印・交代から、あるときだけ） |

おくるんは中身を確かめて（人数・長さ・位置の範囲）、ピッチの図やスコアをカードの部品で描いて送ります（画像のアップロードは要らない）。おくるんの「⚽ さくせん盤で直す」からは `?tab=lineup|result&data=…` でこのページに戻ってきます。

## 紹介の窓口

「📤 さくせん盤を紹介する」（ページのいちばん下）は、おくるんの `shared/tool-share.js`（`data-tool="saqsen"`）。押すとおくるんで緑の紹介カードを作って LINE に送れる（リンクのシェアも選べる）。中身は line-share の `data/hub-links.json` の `key: "saqsen"`。
