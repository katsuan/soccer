# ⚽ さくせん盤（SAQSEN）

サッカー・フットサルのスタメン発表・作戦盤・試合結果のツール。名前は「さくせん盤」（英字は SAQSEN。おくるん＝OQRN と同じ作り方）。ふだん見せるのはひらがなの「さくせん盤」、英字は見出しの下の小さな文字やロゴに使う。送るカードはおくるんで作る。

アイコン（`icon.svg`・`apple-touch-icon.png`・`icon-512.png`）は `python3 tools/icon.py` で作る：おくるんと同じ角の丸い四角に、ピッチの緑。白い S 字の作戦の線（なだらかなインテグラル ∫ のような S。パスの通り道で、さくせんの S）と両端の選手2人、うっすらピッチの線。センターサークルの右下にサッカーボールを置き、サークル＋ボールで Q にも見せる（SAQSEN の Q）。

ファビコンは `icon.svg`（使えないブラウザ向けに `icon-32.png`）、ホーム画面に追加したとき用に `manifest.webmanifest`（四隅まで塗った `icon-maskable-512.png`）。共有したときの画像（`ogp.png`、1200×630）は `python3 tools/ogp.py` で作る。

横長のロゴ（`logo.svg`）も同じスクリプトで作る：ピッチ（盤）の上に「SAQSEN」を白い字で並べ、最初の S・A・E・N はフォント（Jua）、Q はセンターサークル（ハーフウェーラインの真ん中）＋右下のボール。Q の後ろの S はアイコンと同じ線の S で、左下の端（選手の丸）がちょうどボールの下に隠れるところまで寄せる（形は変えない）。見出しの下に出す。

サッカー・フットサルのスタメン発表と作戦盤。選手をピッチに並べて、[おくるん](https://katsuan.github.io/line-share/)の「お知らせカード」で LINE にカードとして送れます。試合結果のカードも作れます。GitHub Pages でそのまま動く静的サイトです。

公開URL: https://katsuan.github.io/soccer/

## できること

- **スタメン・作戦**
  - 作戦盤は1枚のカードにまとめる：右上でコート（サッカー 11人・サッカー 8人制・フットサル 5人）を選び、その下にピッチ、ピッチのすぐ下に操作（👥 相手・⚽ ボール・✏️ ペン・👤 選手・↩️ 戻す。アイコンは絵文字）。「位置をフォーメーションに戻す」で並べ直す
  - 「👕 チーム」の欄に、自チームと相手を左右に向かい合わせて（同じフォーメーションは同じ行）チーム名・人数・色・フォーメーションをまとめる（見出しの右に「FC おくるん vs シティFC・11人」）。人数は − ＋ で1人ずつ（GK を入れて 2〜11 人。ほかの選手の位置はそのまま。決まった並びでなくなると「10人（自由）」）。相手を出しているときは「8 対 7（数的有利）」のように人数差も出る。相手の欄を触ると相手も表示する
  - ユニフォームの色は見分けやすい3色（おくるんの紫・ベリーの赤・白）＋カスタム。明るい色は背番号を濃く。GK はチームと同じ色で、丸の右下に 🧤 を付ける（作戦盤・画像・おくるんのカード。相手の GK も）。カードの選手の丸と見出しの帯も自チームの色になる
  - 選手の編集はモード制：「選手」を押している間だけ、タップで背番号・名前（選手名簿から選べる）。それ以外のときは、ドラッグで移動・タップで選ぶ（作戦盤の操作に集中）
  - 作戦盤：相手（反対向きに並ぶ。消して出し直しても人数・位置は残る）・ボール（⚽）・ペンの線（矢印なしの線。色を選べる・線を全部消す）。「戻す」は移動・線・表示の切り替え・人数やフォーメーションの変更を1つずつ戻す
  - 📁 保存した作戦：「ビルドアップ」「コーナーキック」など場面ごとに、選手の位置・相手・ボール・線を名前を付けて保存（同じ名前は上書きの確認。30件まで。チームの色は含めない）。開く（今の作戦盤に呼び出す。「戻す」で元に戻せる）・複製・名前を変える・消す。この端末（localStorage の `soccer:tactics`）に残る
  - 相手を出していないときは、コート全体に広げて並べる（GK 90%・最前線 18%）。相手を出すと最前線を 33% まで下げ、ほかの選手も GK と最前線の間の同じ割合の高さへ縮める（動かしたあとの配置でも同じ。消すと元に広がる）。相手の出し入れ・フォーメーション・並べ直し・戻す・作戦を開くときは、選手がなめらかに動く
  - 相手を出しているときのフォーメーションの高さは相手と互い違い：上から 相手GK → 相手DF → 自チームFW → 相手MF → 自チームMF → 相手FW → 自チームDF → 自チームGK（FW を前に出しすぎないので、並べ直しが少なくて済む）。横の広がりは列の人数で変える（2人は中央寄り、3人は少し広く、4人以上はサイドいっぱい）
  - 範囲選択：ピッチの何もない所をなぞると、中の選手・相手・ボールが選ばれ、1つをドラッグすると全部が一緒に動く。Ctrl・⌘・Shift を押しながらタップ／なぞると選択に足す
  - フットサルはゴール前が半円（D形）のエリア、サッカーは四角いペナルティエリア
  - 「💬 LINE で共有」の1つのボタンから、送り方をシートで選ぶ
    - 「💬 カードで送る（スタメン発表に）」：おくるんに渡し、ピッチに選手を並べたカードで送る（画像サーバーを使わないので確実に届き、消えない。相手・ボール・線はカードには入らない）。カードのピッチをタップすると、同じ配置の作戦盤が開く
    - 「🖼️ 画像で送る（作戦の共有に）」：作戦盤の画像（相手・ボール・線も入る）を、おくるんの画像サーバー（無料。しばらく使わないと眠り、時間がたつと画像が消えることがある）に保存し、その画像を写真にしたお知らせカードをおくるんで開く（`imageUrl`）。画像をタップすると同じ作戦盤が開く（`imageActionUrl`。相手・ボール・線も入る。線は入る範囲でできるだけ点を残す（1本 24 → 16 → 12 → 8 → 5 点。曲がり角を残す間引き方）。開いた側では点を曲線でつなぐのでカクカクしない。相手の背番号は順番どおりなら省く。位置は整数に丸める。1000 文字に収まらなければ、選手の名前 → 線（新しいものから1本ずつ）→ ボール → 相手の順に外す）。ページを開いた時点で画像サーバーを起こしておく
  - 「📷 画像で保存」（共有の右に並ぶボタン）：相手・ボール・線も入った画像（長押し・共有メニュー・ダウンロード）
  - 試合の情報・👤 選手名簿はたたんだ欄（選手名簿は「👤 選手」の操作と同じ絵文字。👥 は相手だけに使う）。試合の情報（日にち・時間・場所・控え・ひとこと）は、LINE でカードを送るときにカードに入る（入れたものだけ）。日にちと時間はそれぞれ専用の選択で、カードには「10/18（日）9:00」の形で入る
- **試合結果**：チーム名と最終スコアを左右に並べ、その下（同じカードの中）に「得点の内訳（前後半・延長・PK）」をたたむ。得点者・MVP もたたんだ欄（どれも任意）。前半／後半／延長／PK（入れたものだけ出る。同点で PK があれば PK で勝ち負け）・得点（自チーム／相手、時間と名前）・MVP・ひとこと →「💬 LINE で共有」
- 入力した内容と選手名簿はこの端末（localStorage）に残る

## おくるんへの渡し方

`https://liff.line.me/<おくるんの LIFF ID>/card/?kind=lineup|match&data=<JSON を UTF-8 → base64url>&headerTitle=…&title=…&from=soccer`

| kind | data |
|---|---|
| `lineup` | `{ m: "futsal"\|"soccer", f: フォーメーション, t: チーム, o: 相手, s: 控え, c: 自チームの色, pl: [[背番号, 名前, x, y], ...] }`（x・y は 0〜100。左上から、上が攻める向き。先頭が GK） |
| `match` | `{ t, o, us, th（最終。延長を含む）, hu・ht（前半）, su・st（後半）, eu・et（延長）, pu・pt（PK）, g: [["u"\|"t", 分, 名前], ...], mvp }`（内訳と PK はなければ空） |

おくるんは中身を確かめて（人数・長さ・位置の範囲）、ピッチの図やスコアをカードの部品で描いて送ります（画像のアップロードは要らない）。おくるんの「⚽ さくせん盤で直す」からは `?tab=lineup|result&data=…` でこのページに戻ってきます。

## 紹介の窓口

「📤 さくせん盤を紹介する」（ページのいちばん下）は、おくるんの `shared/tool-share.js`（`data-tool="saqsen"`）。押すとおくるんで緑の紹介カードを作って LINE に送れる（リンクのシェアも選べる）。中身は line-share の `data/hub-links.json` の `key: "saqsen"`。
