# ⚽ スタメン・作戦盤

サッカー・フットサルのスタメン発表と作戦盤。選手をピッチに並べて、[おくるん](https://katsuan.github.io/line-share/)の「お知らせカード」で LINE にカードとして送れます。試合結果のカードも作れます。GitHub Pages でそのまま動く静的サイトです。

公開URL: https://katsuan.github.io/soccer/

## できること

- **スタメン・作戦盤**
  - 人数（フットサル 5人／サッカー 11人）とフォーメーションを選ぶと、選手が並ぶ（GK が下、上が攻める向き）
  - 選手はドラッグで移動、タップで背番号・名前（選手名簿から選べる）
  - 作戦盤：相手（同じフォーメーションを反対向きに）・ボール・ペンの線（終わりに矢印。戻す・全部消す）
  - 「💬 スタメンを LINE で送る」：おくるんに渡し、ピッチに選手を並べたカードで送る（相手・ボール・線はカードには入らない）
  - 「📷 作戦盤を画像で保存」：相手・ボール・線も入った画像（長押し・共有メニュー・ダウンロード）
- **試合結果**：スコア・前半・得点（自分たち／相手、時間と名前）・MVP・ひとこと →「💬 結果を LINE で送る」
- 入力した内容と選手名簿はこの端末（localStorage）に残る

## おくるんへの渡し方

`https://liff.line.me/<おくるんの LIFF ID>/card/?kind=lineup|match&data=<JSON を UTF-8 → base64url>&headerTitle=…&title=…&from=soccer`

| kind | data |
|---|---|
| `lineup` | `{ m: "futsal"\|"soccer", f: フォーメーション, t: チーム, o: 相手, s: 控え, pl: [[背番号, 名前, x, y], ...] }`（x・y は 0〜100。左上から、上が攻める向き。先頭が GK） |
| `match` | `{ t, o, us, th, hu, ht（前半。なければ空）, g: [["u"\|"t", 分, 名前], ...], mvp }` |

おくるんは中身を確かめて（人数・長さ・位置の範囲）、ピッチの図やスコアをカードの部品で描いて送ります（画像のアップロードは要らない）。おくるんの「⚽ 配置・結果を直す」からは `?tab=lineup|result&data=…` でこのページに戻ってきます。
